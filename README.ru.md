# VoiceNote

**Портативный, полностью локальный голосовой ввод для Windows.**
Нажмите клавишу, говорите — текст появится в окне, где вы работаете, или в пронумерованном файле заметки.
Всё работает на вашем ПК: без облака, аккаунтов и телеметрии.

## Возможности

**Диктовка**
- Глобальные клавиши: текст в **активное окно** (`F9`), то же с **правкой через LLM** (`F10`), либо в **новый файл заметки**
  (`F7` / `F8`: `note_01.txt`, `note_02.txt`, …). Все клавиши и клавиша отмены меняются.
- Галочка **«Continue»** у каждой клавиши (или `Alt` + клавиша): дописывать в последний файл заметки либо отправлять текст в окно,
  где вы начали, не наводя курсор заново. Двойной сигнал подтверждает переключение (вверх — включено, вниз — выключено).
- **Длинные записи (лекции)**: время не ограничено; звук сразу пишется на диск, режется по паузам на куски 15–40 с и
  распознаётся, пока вы говорите. При сбое недописанная запись превращается в WAV (`recordings\recovered_*.wav`).
- Необязательная **правка через LLM** (пунктуация, слова-паразиты, абзацы): [Ollama](https://ollama.com), [LM Studio](https://lmstudio.ai)
  или любой OpenAI-совместимый локальный сервер. Для Ollama можно выбрать процессор (авто / CPU / GPU).

**Распознавание речи**
- Модели [faster-whisper](https://github.com/SYSTRAN/faster-whisper) от *tiny* до *large-v3-turbo* на **CPU или NVIDIA GPU**.
- Загрузка с **настоящим прогрессом**, пауза / продолжение / остановка, проверка SHA-256; модель можно удалить (✕).
- **Добавление модели ссылкой Hugging Face** (Whisper CTranslate2, SenseVoice, Qwen3-ASR, аудиомодели GGUF). Если в репозитории
  несколько файлов (квантований), **вы выбираете, какой скачать**.
- **Модель уже скачана?** Скопируйте её папку в `models/` — она определится сама (Whisper CTranslate2, SenseVoice, Qwen3-ASR, GGUF; в имени папки должно быть `sense-voice` / `qwen3-asr` для этих двух) и появится в списке через пару секунд.
- Список языков показывает **только языки выбранной модели** (читается из файлов самой модели, где это возможно).
- В списке у каждой модели указан движок: Whisper, SenseVoice, PyTorch, llama.cpp.

**Аудиофайл → текст**
- Перетащите файлы (mp3, wav, m4a, mp4, mkv, ogg, flac, …) или папку в окно: текст по абзацам и, по желанию, субтитры
  **`.srt` / `.vtt`**; пакетная обработка с прогрессом и отменой.

**Прочее**
- **Портативность**: встроенный Python скачивается в папку программы, в систему ничего не ставится. Удаление = удалить папку.
- Нативное окно на **PySide6**, светлая/тёмная тема, значок в трее, автосохранение настроек, 8 языков интерфейса
  (English, Русский, Українська, Español, Deutsch, Français, Português, 简体中文).
- Все внешние ссылки и названия пакетов — в [`sources.json`](sources.json), а не в коде.

## Требования

| | |
|---|---|
| ОС | Windows 10 / 11, x64 |
| Микрофон | любое устройство ввода |
| Интернет | первый запуск (Python и библиотеки) и скачивание моделей |
| Диск | несколько сотен МБ под Python и библиотеки + модели (от 75 МБ до нескольких ГБ) |
| GPU (по желанию) | NVIDIA с актуальным драйвером (для библиотек CUDA 12 — драйвер 527+) |

Linux и macOS **не поддерживаются** (глобальные клавиши, работа с окнами и портативная установка — только Windows).

## Запуск

**Из релиза** (рекомендуется)

1. Скачайте `VoiceNote-<версия>.zip` на странице [Releases](../../releases) и распакуйте куда угодно (путь без спецсимволов надёжнее).
2. Запустите **`run.bat`**. В первый раз он скачает портативный Python и библиотеки в эту же папку (нужен интернет).
3. В блоке *Speech recognition* выберите модель (она скачается при первом использовании) и нажмите **F9**.

**Из исходников**

```bat
git clone https://github.com/kraftkater/VoiceNote.git
cd VoiceNote
run.bat
```

Окно закрыли — программа остаётся в трее. Полный выход — кнопка **Quit** или пункт «Quit» в меню значка: процесс
завершается, модель выгружается из памяти. Если окно не открылось, смотрите `crash.log` рядом с программой.

По умолчанию модель **не выбрана** и ничего не скачивается: выберите её в блоке *Speech recognition* (поле подсвечено).

## Клавиши

| Клавиша | Действие |
|---|---|
| `F9` | Запись → вставка текста в активное окно (повторное нажатие останавливает) |
| `F10` | То же + правка через LLM |
| `F7` / `F8` | Запись → новый файл заметки / то же + правка через LLM |
| `Pause` | Отмена записи (если запись длиннее 15 с — нажать дважды за 3 с; пустой файл заметки удаляется) |
| `Alt` + клавиша | Переключить режим **Continue** для этой клавиши |

Клавиши меняются в окне: нажмите кнопку, затем новую клавишу или комбинацию. Папка заметок и начало имени файла — в блоке *Notes*.
Если целевая программа запущена «от администратора», запускайте VoiceNote тоже от администратора.

### Режим Continue

- `F7` / `F8` дописывают в **последний** файл заметки (через пустую строку), а не создают новый.
- `F9` / `F10` запоминают окно, в котором вы их впервые использовали, и дальше отправляют текст в него; после вставки фокус
  возвращается туда, где вы были. Выключили и включили галочку — запоминается новое окно. Только Windows; если переключиться
  не удалось, текст вставляется в активное окно (об этом пишет журнал).

## Движки распознавания

| Движок | Где работает | Размер установки | Статус |
|---|---|---|---|
| **faster-whisper** (встроен) | CPU / NVIDIA GPU | в базовой установке | основной |
| **Поддержка GPU** (библиотеки CUDA 12) | NVIDIA GPU | ~1 ГБ, по кнопке | работает |
| **SenseVoice** (sherpa-onnx) | CPU | небольшой, по кнопке | работает — только zh / en / ja / ko / yue |
| **PyTorch** (Qwen3-ASR) | CPU / CUDA | несколько ГБ, по кнопке | **экспериментальный** |
| **llama.cpp** (аудиомодели GGUF: Qwen3-ASR, Voxtral, …) | CPU / GPU (Vulkan) | небольшой, по кнопке | **экспериментальный** |

- Движки ставятся в блоке *Extra engines* в `packs/<имя>` — **отдельно от основных библиотек**, поэтому сломать их не могут;
  удаляются там же кнопкой *Remove*. Работают в отдельном процессе: при смене или выгрузке модели процесс завершается и память
  освобождается сразу. По умолчанию ничего из этого не ставится.
- **Поддержка GPU**: CUDA-библиотеки (cuBLAS / cuDNN) ставятся только в `packs\gpu`, PATH не меняется. Нужен лишь драйвер NVIDIA.
  Только NVIDIA — AMD и Intel с этим движком не работают. Окно показывает, где модель реально работает.
- **PyTorch**: установщик определяет видеокарту NVIDIA и драйвер и скачивает подходящую сборку CUDA (для RTX 50xx нужен CUDA 12.8+;
  адреса — `torch_cuda_indexes` в `sources.json`), затем проверяет, что сборка действительно поддерживает вашу карту. Без NVIDIA
  ставится версия для процессора. Если ставили без видеокарты, а потом появилась — удалите PyTorch и поставьте заново.
- **llama.cpp**: скачивается готовый `llama-server` из [релизов llama.cpp](https://github.com/ggml-org/llama.cpp/releases)
  (сборка Vulkan, если найдена видеокарта, иначе для процессора). Запускается отдельным процессом на `127.0.0.1`; на Windows он
  привязан к программе (job object), поэтому не остаётся в памяти, даже если VoiceNote закрыли из диспетчера задач.
  GGUF-репозитории, сделанные для других программ (например, CrispASR), в нём не запустятся.
- Не поддерживаются: модели NVIDIA NeMo (`.nemo`), а также чистые веса ONNX / Transformers без подходящего движка.
- Языки: для Whisper и SenseVoice список читается из файлов скачанной модели (теги `<|ru|>` в `tokenizer.json` / `tokens.txt`);
  пока модель не скачана, показывается общий список. У Qwen3-ASR используются 30 языков из карточки модели.

### Модели

- ↗ рядом с моделью открывает её страницу на Hugging Face; ⏸/▶ — пауза и докачка; ■ — остановка (частичные файлы удаляются);
  ✕ — удаление файлов модели (добавленная по ссылке модель пропадает и из списка, встроенные остаются).
- *Add a model from Hugging Face*: вставьте ссылку — программа проверит содержимое репозитория и добавит модель, если формат
  поддерживается. Если репозиторий GGUF содержит несколько файлов, будет предложено выбрать квантование (позже его можно
  сменить в списке *Model file*). Для GGUF с отдельным аудиоэнкодером скачивается и файл `mmproj`.
- Основной вес — модели: tiny ≈ 75 МБ, base ≈ 145, small ≈ 480, medium ≈ 1,5 ГБ. Запись во время работы занимает ≈ 115 МБ на час
  в `recordings` и после обработки удаляется (если не включено *Keep a WAV copy*).

## Аудиофайл → текст

Блок *Audio file → text*: кнопки выбора файлов / папки или перетаскивание в окно. Папки обрабатываются вместе с вложенными, файлы идут
по очереди, обработку можно отменить. Берутся модель, язык и процессор из блока *Speech recognition*. Результаты кладутся в папку заметок:

| Файл | Содержимое |
|---|---|
| `имя.txt` | текст по абзацам (если такой файл есть, добавляется ` (2)`, ничего не затирается) |
| `имя.srt` / `имя.vtt` | субтитры (галочки); у Whisper время точное, у остальных движков — примерное |

Файл читается в память целиком (1 час записи ≈ 230 МБ). Нельзя запускать во время записи с микрофона или загрузки модели.

## Настройки и файлы

Всё хранится в папке программы:

| Путь | Содержимое |
|---|---|
| `settings.json` | все настройки (сохраняются автоматически, кнопки «Сохранить» нет) |
| `sources.json` | адреса загрузок и названия пакетов — правьте, если ссылка изменилась |
| `models/` | скачанные модели |
| `packs/` | дополнительные движки (`gpu`, `sensevoice`, `pytorch`, `llamacpp`) |
| `notes/` (по умолчанию) | заметки `F7` / `F8` и результаты *Audio file → text* |
| `recordings/` | временный звук текущей записи |
| `crash.log`, `worker.log`, `packs/install.log` | диагностика |

Ключи `sources.json`: `python_embed_urls`, `get_pip_urls`, `pip_index_urls` (зеркала, пробуются по очереди), `pip_extra_index_urls`,
`torch_cuda_indexes`, `hf_base` (сюда можно вписать зеркало), `packs` (закрепление версий, например `"torch==2.5.1"`),
`llamacpp_release_api`, `llamacpp_assets`, `whisper_repos`, `extra_models`, `keep_wheels` (оставлять скачанные пакеты в
`packs\_cache` для установки без интернета). Битый файл игнорируется — берутся встроенные значения.

Свой язык интерфейса: скопируйте `lang\ru.json` в `lang\xx.json`, переведите значения, в поле `"_name"` впишите название языка.

## Конфиденциальность

- Звук и текст не покидают ваш компьютер. Телеметрии и аккаунтов нет.
- Сеть используется только для загрузок, которые вы запросили: Python / pip (python.org, bootstrap.pypa.io, PyPI), модели
  (Hugging Face), сборки PyTorch (download.pytorch.org), `llama-server` (GitHub) — и для **адреса локального LLM-сервера**,
  который вы указали (Ollama / LM Studio / свой).

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Окно не открылось | `crash.log` рядом с `run.bat` |
| Клавиша ничего не делает | Её может занимать другая программа — смените клавишу. Антивирусы иногда реагируют на глобальные хуки клавиатуры (см. ниже) |
| Текст не вставляется в программу | Она запущена от администратора — запустите VoiceNote тоже от администратора |
| GPU не используется | В блоке *Speech recognition → Processor* видно, что где работает; поставьте *GPU support* (только NVIDIA) |
| Ошибка про `msvcp140.dll` | Установите «Microsoft Visual C++ Redistributable x64» |
| Дополнительный движок не работает | `worker.log` (процесс движка) и `packs/install.log` (установка) |
| Ссылка для загрузки перестала работать | Поправьте `sources.json`; пакеты, исчезнувшие из PyPI, можно положить вручную как `.whl` в `packs\_cache` |

> **Про антивирус.** Глобальные клавиши сделаны на библиотеке [`keyboard`](https://github.com/boppreh/keyboard), которая ставит
> низкоуровневый хук клавиатуры. Некоторые антивирусы подозревают любую программу, которая так делает. VoiceNote не записывает
> нажатия клавиш; исходный код открыт.

## Статус проекта

VoiceNote находится в стадии **beta**. Автотесты (`pytest`, запускаются в CI) покрывают чистую логику: проверку настроек, нарезку звука,
субтитры, выбор файлов модели, переводы. Всё, что зависит от железа и ОС (CUDA, Vulkan, глобальные клавиши, окно Qt,
дополнительные движки), в CI не запускается и проверялось вручную на ограниченном наборе машин; **экспериментальные** движки на вашем ПК
могут вести себя иначе. Если что-то не работает — [создайте issue](../../issues/new/choose) и приложите логи.
